คำตอบสำหรับคำถามที่พบบ่อยที่สุดเกี่ยวกับ Cambiora

คำถาม

  1. อัตราแลกเปลี่ยนมาจากไหน และอัปเดตแค่ไหน
  2. Cambiora ใช้งานได้โดยไม่มีอินเทอร์เน็ตไหม
  3. ทำไมธนาคารหรือบัตรของฉันแสดงจำนวนเงินต่างออกไป
  4. Cambiora Pro มีอะไรบ้าง และราคาเท่าไร

  6. จะเพิ่มวิดเจ็ตบนหน้าจอหลักได้อย่างไร
  7. ฉันพบข้อผิดพลาด ควรทำอย่างไร

อัตราแลกเปลี่ยนมาจากไหน และอัปเดตแค่ไหน

Cambiora ใช้อัตราอ้างอิงของธนาคารกลางยุโรป (ECB) ซึ่งประกาศในช่วงบ่ายของวันทำการ ส่วนวันหยุดสุดสัปดาห์และวันหยุดนักขัตฤกษ์จะใช้อัตราล่าสุดต่อไป

  • สกุลเงินอื่น รวมถึงทองคำ โลหะเงิน และแพลทินัม มาจาก currency-api วันละครั้ง
  • คริปโทเคอร์เรนซีมาจาก Coinbase แบบสด และอัปเดตทุก 60 วินาทีขณะที่แอปเปิดอยู่

แอปจะแสดงวันที่และเวลาที่อัปเดตอัตราเสมอ

Cambiora ใช้งานได้โดยไม่มีอินเทอร์เน็ตไหม

ได้ Cambiora เก็บอัตราที่โหลดล่าสุดไว้ในอุปกรณ์ของคุณ การแปลงและการคำนวณจึงใช้ได้บนเครื่องบิน เมื่อไม่ได้เปิดโรมมิ่ง หรือในที่ที่ไม่มีสัญญาณ เมื่อกลับมาออนไลน์ แอปจะโหลดอัตราใหม่ทันที

มีเพียงการเปิดแอปครั้งแรกเท่านั้นที่ต้องใช้อินเทอร์เน็ตเพื่อโหลดอัตรา

ทำไมธนาคารหรือบัตรของฉันแสดงจำนวนเงินต่างออกไป

Cambiora ใช้อัตรากลาง ธนาคาร ผู้ออกบัตร และร้านรับแลกเงินใช้อัตราของตนเองที่บวกส่วนต่าง และมักเก็บค่าธรรมเนียมการใช้จ่ายสกุลเงินต่างประเทศ หากต้องการให้ใกล้เคียงกับยอดในใบแจ้งยอดของคุณ:

  • ค่าธรรมเนียมเพิ่มเติม (Pro): ที่ การตั้งค่า → อัตราแลกเปลี่ยน → ค่าธรรมเนียมเพิ่มเติม ให้กำหนดเปอร์เซ็นต์และสกุลเงินหลักของคุณ Cambiora จะรวมค่าธรรมเนียมนี้ในทุกการแปลงระหว่างสกุลเงินหลักกับสกุลเงินต่างประเทศ
  • อัตราที่กำหนดเอง (Pro): ที่ การตั้งค่า → อัตราแลกเปลี่ยน → อัตราที่กำหนดเอง ให้ป้อนอัตราที่คุณได้รับสำหรับสกุลเงินหนึ่ง เช่น จากร้านรับแลกเงิน

Cambiora Pro มีอะไรบ้าง และราคาเท่าไร

Cambiora ใช้ได้ฟรีและไม่มีโฆษณา Pro เป็นการซื้อครั้งเดียว ไม่ใช่การสมัครสมาชิก ราคาจะแสดงในสโตร์และในแอป Pro ปลดล็อกฟีเจอร์ต่างๆ เช่น:

  • สกุลเงินพร้อมกันได้ไม่จำกัด (ฟรี: สูงสุด 3 สกุล)
  • สแกนราคาด้วยกล้อง
  • วิดเจ็ตบนหน้าจอหลัก
  • ประวัติอัตราแลกเปลี่ยนสูงสุด 5 ปี (ฟรี: สูงสุด 3 เดือน)
  • ธีมสี 5 แบบ

ดูฟีเจอร์ Pro ทั้งหมดและซื้อได้ในแอปที่ การตั้งค่า → Cambiora Pro

เปลี่ยนโทรศัพท์ใหม่: จะได้ Pro คืนอย่างไร

Pro ผูกกับบัญชีสโตร์ของคุณ คือบัญชี Google หรือ Apple ID ลงชื่อเข้าใช้ด้วยบัญชีเดียวกันในอุปกรณ์ใหม่ ติดตั้ง Cambiora แล้วแตะ การตั้งค่า → Cambiora Pro → กู้คืนการซื้อ

การซื้อใน Google Play ใช้กับ App Store ไม่ได้ และในทางกลับกันก็เช่นกัน

จะเพิ่มวิดเจ็ตบนหน้าจอหลักได้อย่างไร

วิดเจ็ตมีให้ใน Cambiora Pro ขณะนี้สำหรับ Android เท่านั้น วิดเจ็ตแปลงสกุลเงินแสดงจำนวนเงินในสกุลเงินสูงสุด 3 สกุล วิดเจ็ตอัตราแลกเปลี่ยนแสดงอัตราของคู่สกุลเงินพร้อมแนวโน้ม

  • แตะค้างที่พื้นที่ว่างบนหน้าจอหลัก แล้วเลือก วิดเจ็ต
  • ค้นหา Cambiora แล้วลากวิดเจ็ตที่ต้องการไปที่หน้าจอหลัก
  • เลือกสกุลเงิน แล้วแตะ เพิ่มวิดเจ็ต

แต่ละวิดเจ็ตมีสกุลเงินของตัวเอง อัตราจะอัปเดตประมาณชั่วโมงละครั้ง

ฉันพบข้อผิดพลาด ควรทำอย่างไร

เขียนถึงเราได้ที่ contact@cambiora.com สิ่งที่ช่วยได้มากที่สุดคือรายงานข้อผิดพลาดจากแอป: การตั้งค่า → เกี่ยวกับ Cambiora → รายงานข้อผิดพลาด → ส่งทางอีเมล

Cambiora เก็บรายงานข้อผิดพลาดไว้ในอุปกรณ์ของคุณเท่านั้นและไม่ส่งอะไรเองเลย คุณจะเห็นข้อความก่อนส่งอีเมล หากไม่มีรายงาน โปรดอธิบายสั้นๆ ว่าคุณทำอะไร และแจ้งรุ่นอุปกรณ์กับเวอร์ชันของแอป (ที่ การตั้งค่า → เกี่ยวกับ Cambiora)
